# Solverin — reglas de trabajo

- Respuestas sin saludos, preámbulos, introducciones ni explicaciones teóricas.
- El ahorro de tokens nunca justifica código incompleto: prohibidos los placeholders (`TODO`, "completar aquí"),
  funciones abreviadas o lógica inventada. Todo módulo entregado debe estar completo, compilar y funcionar en Android.
- Motor preflop: `engine/` (Kotlin JVM puro, tests con `./gradlew :engine:test`). App: `app/`.
